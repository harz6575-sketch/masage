# Fascia Gun landing

Яскравий односторінковий лендинг перкусійного масажера.

## Що є
- адаптивний дизайн для ПК і телефона;
- 6 наданих фото товару;
- окремі CTA-кнопки між блоками;
- без вибору кількості у формі;
- форма: ім'я + телефон;
- Telegram-заявки через Vercel API;
- ціна 889 грн → 539 грн;
- таймер без відображення дат акції;
- без блоку «З цим товаром часто замовляють»;
- без блоку про переваги Укрпошти.

## Vercel
Додайте змінні середовища:
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`

Після деплою форма надсилає заявку в Telegram через `/api/order`.


Оновлення: додано помітний таймер у верхній частині сторінки та покращено адаптивність для мобільних екранів.


Таймер автоматично рахує до 23:59:59 поточного дня без показу дати. Форма передає UTM-мітки (якщо вони є) у Telegram. У повідомленні заявки немає рядка про оплату при отриманні.
